# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on learning the basic components of cloud
computing infrastructure. Using KillerCoda, Linux commands, and GitHub, I
explored compute, storage, networking, operating systems, and identity and
access management.

The activity helped me understand how these components work together and why
proper documentation is important in cloud computing.

## Objectives

- Identify the main components of cloud infrastructure.
- Investigate Linux hardware and software resources.
- Understand compute, storage, networking, and identity resources.
- Learn how cloud components work together.
- Create technical documentation using Markdown.
- Organize my Cloud Computing Portfolio on GitHub.

## Cloud Infrastructure Components

- **Compute** – Provides processing power for applications and services.
- **Storage** – Stores files, applications, and data.
- **Networking** – Allows devices and cloud services to communicate.
- **Operating System** – Manages computer hardware and software.
- **IAM** – Manages users, permissions, and access to cloud resources.

## Tools Used

- **KillerCoda Playground** – Linux cloud environment
- **Ubuntu Linux** – Operating system
- **Linux Terminal** – Used to check system information
- **GitHub** – Used to manage my portfolio
- **Markdown** – Used for documentation
- **Microsoft PowerPoint** – Used to create the cloud diagram

## Linux Commands Executed

| Command | Purpose |
|---|---|
| `cat /etc/os-release` | Checks the operating system |
| `uname -r` | Checks the kernel version |
| `lscpu` | Checks CPU information |
| `nproc` | Checks the number of CPU cores |
| `free -h` | Checks RAM and memory |
| `df -h` | Checks disk space |
| `findmnt` | Checks mounted file systems |
| `hostname` | Checks the system hostname |
| `hostname -I` | Checks the IP address |
| `ip addr` | Checks network information |
