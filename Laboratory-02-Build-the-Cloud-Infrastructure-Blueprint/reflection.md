# Mission Reflection

  For me, the most important cloud infrastructure component is **networking**
because it connects users, servers, applications, and other cloud resources.
Even if a cloud system has enough processing power and storage, users still
need a reliable network to access its services. A good network helps
information move smoothly between different resources and allows users to
access cloud applications anytime. Linux also plays an important role in cloud computing because it provides a
reliable, flexible, and secure operating system for running servers and
applications. During this activity, I used different Linux commands to check
the CPU, memory, storage, operating system, and network information of the
cloud environment. This helped me become more familiar with using the
terminal and understanding system information.

  I also learned that technical documentation is important before deploying
infrastructure because it provides a clear record of the resources,
configurations, and decisions involved in a project. Proper documentation can
help prevent mistakes, make troubleshooting easier, and help other users
understand how the system is organized. Throughout this laboratory activity, I developed new skills in using Linux
commands, understanding cloud infrastructure components, creating technical
documentation, designing a cloud architecture diagram, and managing files in
GitHub. I also learned how compute, storage, networking, and identity
services work together to support cloud systems.

  My GitHub portfolio improved because I added my laboratory reports,
infrastructure information, cloud component explanations, cloud provider
comparison, and architecture diagram. Overall, this mission gave me a better
understanding of cloud computing and helped improve my confidence in using
Linux, GitHub, Markdown, and technical documentation. It also helped me
realize that careful planning and proper documentation are important skills
for anyone working with cloud infrastructure.
