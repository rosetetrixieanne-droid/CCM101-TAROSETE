# Reflection

This activity gave me my first hands-on experience working in a cloud-based Linux environment using KillerCoda. I learned how to access an Ubuntu playground, explore the terminal, and use basic Linux commands to check system information.

I also learned how to create a new Linux user with a home directory, Bash shell, and sudo privileges. Logging in to the new account helped me understand how user accounts and permissions work in Linux.

One of the things I learned from this activity is the importance of using commands correctly and carefully. Commands such as `whoami`, `pwd`, and `hostname` helped me identify important information about the system. I also became more comfortable working with the Linux terminal.
