
# Checkpoint 7 - Mission Reflection

## 1. Importance of Automation

Automation is important when managing hundreds of cloud servers because it saves time and reduces repetitive manual work. Instead of configuring and checking each server one by one, cloud engineers can use scripts to perform tasks automatically. Automation also helps maintain consistency, improve efficiency, and reduce human errors. For example, a Bash script can automatically back up important application data on a schedule.

## 2. Potential Dangers of Automation

Although automation is helpful, it can also be dangerous when a script contains mistakes. A destructive typo in a script scheduled to run on 1,000 servers could delete important files, stop services, or damage system configurations across all affected servers. This could cause downtime, data loss, and financial problems. To prevent these risks, engineers should test scripts in a safe environment, review commands carefully, create backups, and deploy changes gradually.

## 3. Bash Script vs. Docker Compose YAML

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. A Bash script contains commands that execute tasks step by step, such as creating directories and compressing backup files. Docker Compose YAML, on the other hand, describes how containers and services should be configured, including their images, ports, networks, and environment variables. Both require correct syntax and careful planning, but they serve different purposes in cloud operations.
