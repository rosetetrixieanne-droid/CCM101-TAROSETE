# Automation Research

## 1. Bash Script

A Bash script is a file that contains Linux commands
that can be executed together automatically. The line
#!/bin/bash tells the operating system to use Bash
to interpret and execute the script.

## 2. Variables

Variables store values such as folder paths and
filenames. Using variables like BACKUP_DIR makes a
script easier to update because the value can be
changed in one place instead of changing it in
multiple commands.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs
automatically at a specified time. It is useful in
cloud operations because it can automate repetitive
tasks such as backups and system maintenance.
