# Security Audit Report

## 1. Principle of Least Privilege (PoLP)
The Principle of Least Privilege means that users and applications should only be given the permissions needed to perform their assigned tasks. This helps protect the system from unauthorized access and minimizes possible damage if an account is hacked.

## 2. Attack Surface
The attack surface includes all the possible entry points that an attacker could use to access or attack a virtual machine. These may include open network ports, active services, and user accounts with weak passwords or security settings.

## 3. Default Deny Policy
A Default Deny policy blocks all incoming connections unless they are specifically permitted. This improves security by allowing only trusted and approved services to receive network traffic, reducing the risk of unauthorized access.
