# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that users and
applications should only receive the permissions they
need to perform their tasks. This helps prevent
unauthorized access and reduces the damage that can
happen if an account is compromised.

## 2. Attack Surface

The attack surface refers to all the possible ways an
attacker could access or exploit a virtual machine.
Examples include open network ports, running services,
and accounts with weak security.

## 3. Default Deny Policy

A Default Deny policy blocks incoming connections
unless they are explicitly allowed. It is safer because
only approved services can receive traffic instead of
allowing everything and trying to block threats one
by one.
