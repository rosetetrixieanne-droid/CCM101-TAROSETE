# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud object storage using MinIO. The goal is to build a proof-of-concept storage environment for a photo-sharing application that needs to store a large number of user-uploaded images.

## Objectives

* Research the different types of cloud storage.
* Compare Block Storage, File Storage, and Object Storage.
* Deploy MinIO using Docker.
* Access the MinIO Web Console.
* Create a bucket named `client-photos`.
* Upload a test file to the bucket.
* Document the deployment process.

## Tools Used

* KillerCoda Ubuntu Playground
* Docker
* MinIO
* MinIO Web Console
* Linux Terminal
* Git and GitHub
* Markdown

## Skills Learned

* Understanding cloud storage types
* Deploying a storage server using Docker
* Managing Docker containers
* Using the MinIO Web Console
* Creating and managing object storage buckets
* Uploading objects to cloud storage
* Using Linux command-line commands
* Documenting cloud infrastructure tasks
