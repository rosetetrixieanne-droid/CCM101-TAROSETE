# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides many cloud services that organizations can use to run applications, store data, manage networks, and build scalable systems. AWS is widely used by startups, enterprises, government organizations, and developers.

## Global Infrastructure

AWS has a large global infrastructure made up of geographic Regions and Availability Zones. AWS Regions are separate geographic areas, while Availability Zones are isolated locations inside a Region. This infrastructure helps organizations build applications that are highly available and reliable.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources. Users can access services such as EC2, S3, IAM, and RDS through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store files, images, backups, and other data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create and manage isolated virtual networks in AWS.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources by managing users, roles, and permissions.

## Three Advantages

1. AWS provides a very wide range of cloud services.
2. AWS has a large global infrastructure that supports scalable applications.
3. AWS provides flexible services that can be used by both startups and large organizations.

## Typical Enterprise Use Cases

AWS can be used for web applications, mobile applications, databases, backup systems, data analytics, e-commerce platforms, and enterprise applications.
