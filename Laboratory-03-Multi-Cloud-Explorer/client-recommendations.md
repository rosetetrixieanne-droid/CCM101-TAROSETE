# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because it provides flexible services that can support a small application and scale as the company grows. The startup can begin with a relatively simple cloud architecture and add more resources when the number of users increases. AWS also provides many services that can be used without building the entire infrastructure manually.

### Recommended Services

* Amazon EC2 – virtual servers
* Amazon S3 – object storage
* Amazon RDS – managed relational database
* Amazon Elastic Load Balancing – distributes application traffic

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and supports hybrid cloud environments. This can make it easier for the university to move selected services to the cloud while continuing to use existing Microsoft systems.

### Recommended Services

* Azure Virtual Machines
* Microsoft Entra ID
* Azure SQL Database
* Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is recommended because the company focuses on Artificial Intelligence and Machine Learning applications. Google Cloud provides AI and ML services and infrastructure designed for demanding workloads. It also provides strong tools for data processing and cloud-native development.

### Recommended Services

* Compute Engine
* Vertex AI
* Cloud Storage
* Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong choice for a global e-commerce company because it provides a large global infrastructure and services for highly available and scalable applications. The company can distribute workloads across regions and Availability Zones and automatically scale resources when traffic increases. This is useful for an online shopping platform that may experience large changes in traffic.

### Recommended Services

* Amazon EC2
* Amazon S3
* Elastic Load Balancing
* Amazon RDS
* Amazon CloudFront
