# Mission Reflection

During this laboratory activity, I learned more about the three major cloud platforms: AWS, Microsoft Azure, and Google Cloud Platform. Among the three, Google Cloud impressed me the most because of its strong focus on Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. I also learned that AWS has a very wide range of cloud services, while Azure is very useful for organizations that already use Microsoft technologies.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, cloud storage, networking, databases, identity management, security, and other services. They also use regions and other global infrastructure to provide reliable cloud services. Although their services have different names, many of them perform similar functions. For example, Amazon EC2, Azure Virtual Machines, and Google Compute Engine can all be used to run virtual machines in the cloud.

I also learned that business requirements are very important when selecting a cloud platform. A company should not choose a cloud provider only because it is popular. It should consider its budget, existing technologies, application requirements, scalability, security, location, and future plans. For example, Azure is a good choice for a company that already uses Microsoft technologies, while Google Cloud can be a good choice for AI and Machine Learning projects.

Acting as a Cloud Solutions Consultant helped me understand that cloud computing is not only about knowing technical services. It is also about understanding the needs of a client and matching those needs with the right technology. I learned how to compare services and make recommendations based on business requirements.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added another organized laboratory folder containing research, comparisons, recommendations, screenshots, and my reflection. This makes my portfolio more complete and shows my progress in learning cloud computing.
