# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud computing platform developed by Google. It provides infrastructure, storage, databases, networking, artificial intelligence, machine learning, analytics, and application development services.

## Global Infrastructure

Google Cloud provides cloud infrastructure across multiple global regions and zones. Its global network is designed to provide high performance, reliability, and low latency for applications and services.

## Cloud Management Console

Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources. Users can manage virtual machines, storage, databases, Kubernetes clusters, networking, and AI services through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run applications and workloads.

### 2. Cloud Storage

Cloud Storage is an object storage service used for storing files, backups, media, and other data.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy and manage containerized applications.

### 4. Cloud IAM

Cloud Identity and Access Management controls access to Google Cloud resources through permissions, roles, and identities.

## Three Advantages

1. Google Cloud has strong artificial intelligence and machine learning capabilities.
2. Google Cloud provides strong support for Kubernetes and containerized applications.
3. Google operates a large global network designed for performance and scalability.

## Typical Enterprise Use Cases

Google Cloud can be used for artificial intelligence, machine learning, data analytics, Kubernetes deployments, web applications, databases, and large-scale enterprise applications.
