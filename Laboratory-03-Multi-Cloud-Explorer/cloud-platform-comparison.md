## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, machine learning, IoT, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works well with Windows Server, Microsoft 365, Active Directory-related environments, and other Microsoft enterprise technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is especially strong in Artificial Intelligence, Machine Learning, and Kubernetes. Its AI services and Google Kubernetes Engine make it a strong choice for organizations developing AI and containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it offers a wide selection of cloud services and provides many options for different types of applications. It is also useful for learning because many different cloud computing concepts can be practiced using its services.
